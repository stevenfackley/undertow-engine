# Software Design Documents (SDD)

This directory contains SDDs that describe the technical design and implementation details for undertow-engine components.

## Contents

_Add SDD documents here as components are designed._

## Template

Each SDD should include:

- **Overview** — what is being built and why
- **Background** — relevant context and prior art
- **Design** — data models, interfaces, algorithms, and component interactions
- **Alternatives Considered** — other approaches evaluated and why they were rejected
- **Security & Privacy** — threat model and mitigations
- **Testing Plan** — how correctness will be verified
- **Rollout Plan** — phased delivery strategy
