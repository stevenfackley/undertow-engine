# undertow-engine Documentation

This directory contains all project documentation for **undertow-engine** — a standalone Python microservice for automated short-form video compositing and headless social media deployment.

## Directory Structure

| Directory | Description |
|-----------|-------------|
| [`prd/`](prd/) | Product Requirements Documents — goals, user stories, and feature specs |
| [`sdd/`](sdd/) | Software Design Documents — technical design and implementation details |
| [`architecture/`](architecture/) | Architecture diagrams and Architecture Decision Records (ADRs) |
| [`api/`](api/) | API reference documentation |
| [`runbooks/`](runbooks/) | Operational runbooks for deployment, maintenance, and incident response |
